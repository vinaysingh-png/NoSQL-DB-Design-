12.Using Neo4j Cypher, create a social-network graph containing Person nodes and relationships such as FRIENDS_WITH, FOLLOWS, and WORKS_AT. Write queries to find a person's friends and followers. 
  // Create Persons and relationships
  CREATE (p1:Person {name: "Aarav"})
  CREATE (p2:Person {name: "Neha"})
  CREATE (p1)-[:FRIENDS_WITH]->(p2)
  CREATE (p2)-[:FOLLOWS]->(p1)

  // Query to find a person's friends
  MATCH (p:Person {name: "Neha"})-[:FRIENDS_WITH]->(friend)
  RETURN friend.name

  // Query to find a person's followers
  MATCH (follower)-[:FOLLOWS]->(p:Person {name: "Neha"})
  RETURN follower.name

13.Design a shopping/e-commerce graph using Neo4j containing Customer, Product, Category, and Order nodes. Create appropriate relationships and write Cypher queries to find products purchased by a particular customer. 
  // Create Nodes
  CREATE (cust:Customer {customerId: "C100", name: "Neha"})
  CREATE (cat:Category {catId: "CAT1", name: "Electronics"})
  CREATE (prod:Product {productId: "P99", name: "Wireless Mouse", price: 799})
  CREATE (ord:Order {orderId: "ORD500", date: "2026-10-09"})

  // Create Relationships
  CREATE (prod)-[:BELONGS_TO]->(cat)
  CREATE (cust)-[:PLACED]->(ord)
  CREATE (ord)-[:CONTAINS]->(prod)

  // Query products purchased by a particular customer
  MATCH (c:Customer {name: "Neha"})-[:PLACED]->(o:Order)-[:CONTAINS]->(p:Product)
  RETURN p.name AS ProductName, p.price AS Price
